# Terra Bento — дизайн-система Spanish Reader

**Версия:** 1.0 · согласовано 26 ноября 2026 г.
**Статус:** утверждённое визуальное направление и стартовые токены для реализации. Размеры, контрастность, гарнитуры и взаимодействия проверяются на реальном Android; это не результат device-тестов.
**Связь:** [SPEC.md](../SPEC.md) — продуктовые сценарии и поведение. Этот документ определяет оформление, не отменяя их.

## 1. Направление

- Soft Material: Material 3 / Jetpack Compose как основа интерактивных компонентов, собственная тема, мягкие тональные поверхности, короткая обратная связь.
- Bento UI: функциональные модули и сетка действий, не превращать каждый элемент списка в карточку.
- Mediterranean Modern: тёплая известковая бумага, глиняные/терракотовые поверхности, burnt orange в действиях, тёмные тёплые чернила.
- Без фотографий, декоративных иллюстраций, текстур и искусственно генерируемых обложек. Матовые поверхности, минимум теней.
- Одна светлая тема в MVP; динамические системные цвета не должны незаметно заменять фирменную палитру. Альтернативные темы не обязательны.

## 3. Типографика

Утверждённая стартовая пара: **Manrope** (UI) + **Literata** (читаемый текст и крупные названия текстов в продолжении чтения). В Reader по умолчанию антиква, пользователь может переключиться на гротеск и изменить размер. Проверить реальные начертания, латиницу с испанской диакритикой, кириллицу, перенос длинных заголовков, системный font scale и лицензии. В чат-макетах применялись системные заменители, а не реальные файлы шрифтов. Размеры ниже — стартовые для прототипа, не финальный масштаб.

| Роль | Стартовый размер |
|---|---|
| Заголовок экрана UI | 26–30 sp, semibold |
| Заголовок раздела | 20–21 sp, semibold |
| Основной UI-текст | 14–16 sp |
| Метаданные | 12–13 sp |
| Заголовок текста Reader | 28–30 sp, regular |
| Читаемый текст | 19–20 sp, regular; межстрочный 1.6–1.76 |
| Числа и прогресс | Tabular numbers, если поддерживает шрифт |

Выравнивание Reader влево, без принудительного justify. Не обрезать важные надписи для соблюдения фиксированной высоты.

## 5. Компоненты

- Primary button: burnt orange + белый текст, мягкая pill-форма.
- Tonal button: orange tint + burnt orange; outline button: тонкая рамка, burnt orange; text button: без заливки.
- Bento tile: Clay, иконка 24 dp, подпись, при необходимости короткое пояснение. Равные ячейки 2×2, вся площадь интерактивна.
- Continue card: тёплая тональная поверхность, текстовое название без изображения, прогресс, акцент продолжения; вся карточка доступна для тапа.
- Vocabulary generation banner: Orange tint, одна широкая плашка.
- Text list item: плоский список, название и метаданные, тонкие разделители; прогресс оранжевый. Без отдельных контейнеров вокруг каждой записи.
- Navigation: две вкладки «Библиотека» и «Словарь», контурные иконки, active burnt orange и мягкий индикатор.
- Popover: floatingSurface, тонкая рамка или минимальная тень, только перевод и стрелка раскрытия. Не сдвигать текст. Не затемнять экран. Голубой фокус и янтарная маркировка остаются в тексте.
- Full card / Sentence Mode: floatingSurface, крупное скругление, прокрутка, акцентные кнопки, приглушённые поверхности только для функциональных модулей. Геометрия полной карточки и Sentence Mode проверяется отдельно.
- Chips: активные orange tint, неактивные контурные; текстовый признак выбранного состояния.
- Иконки: единый контурный стиль, скруглённые линии; не смешивать несогласованные наборы.

## 6. Применение к экранам

**Library:** наиболее выразительный экран. Сверху продолжить чтение; затем 2×2 (вставить текст, загрузить файл, по ссылке, сгенерировать текст); широкая плашка «Текст из моих слов»; три текущих текста с прогрессом и «Ещё»; «Хочу почитать» ниже; две вкладки закреплены снизу. Без обложек. Не добавлять новых сценариев, не утверждённых SPEC.

**Reader:** почти чистая бумажная страница. Назад, название, Aa, ненавязчивый прогресс. Минимум оранжевого. Книжный текст, семантические выделения и компактный popover. Не переносить Bento-сетку в основной текст.

**Import / Generate:** больше акцентов в действиях, нейтральные поля и понятная иерархия; детальные экраны ещё проектируются.

**Vocabulary:** спокойные плоские списки, тональные фильтры, оранжевый для активных действий. Детальная компоновка и поведение ещё проектируются.

**Visual Grammar:** цвета ролей внутри схем; не окрашивать ими весь Reader. Смысл должен читаться по подписям и структуре, не только по цвету.

## 7. Motion

| Действие | Стартовая длительность |
|---|---|
| Появление popover | 120–160 ms |
| Раскрытие полной карточки | 220–280 ms |
| Реакция Bento-модуля на тап | 100–150 ms |
| Раскрытие списка | 180–220 ms |

Мягкие короткие переходы без декоративного параллакса, подпрыгиваний и выраженной пружины. Показ доступного перевода не задерживать ради анимации. Учитывать системные настройки уменьшения анимаций.

## 8. Реализация и проверки

- Централизовать семантические токены в Compose theme (ColorScheme, дополнительные reader/grammar colors, Typography, Shapes, spacing, motion). Не хардкодить палитру в отдельных экранах.
- Сохранить возможность корректировки токенов после теста, не меняя продуктовую архитектуру.
- Проверить контраст текста и иконок (ориентир WCAG AA: 4.5:1 обычный текст, 3:1 крупный текст и необходимые нетекстовые компоненты), состояния disabled/pressed/focused, доступность через TalkBack. Низкоконтрастные декоративные поверхности не заменяют контрастную информацию.
- Проверить на Samsung Galaxy S25 Plus, включая масштабирование, длинные русские подписи и испанские заголовки, прокрутку, зоны касания, размещение popover у краёв и работу при открытой карточке.
- В текущем состоянии не проверены реальная сборка Compose, контраст всей матрицы состояний, реальные шрифты и анимации на устройстве. Стартовые токены согласованы как основа, а не как результаты измерений.
