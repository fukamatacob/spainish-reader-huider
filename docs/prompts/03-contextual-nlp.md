# PoC 03 — сравнительный контекстный NLP

Ты инженер, выполняющий один ограниченный технический эксперимент в репозитории fukamatacob/spainish-reader-huider. Прочитай SPEC.md, docs/POC_PLAN.md, docs/TECHNICAL_AUDIT.md и при необходимости docs/DESIGN_SYSTEM.md. Следуй актуальной SPEC, не историческим UX-решениям донора. Не реализуй весь продукт. Проверь git status, сохрани чужую работу, используй отдельную ветку/worktree либо уже выделенную рабочую ветку. Не пушь и не сливай main без явного указания. Не используй destructive reset. Не публикуй секреты, личные данные, большие базы/модели/APK и нелицензированные исходные данные. Для существенных загрузок/установок проверь объём и разрешение. Не запрашивай ключи в чат/логи; используй только разрешённый локальный секрет. Не выдавай результаты mock/эмулятора/предположения за live/device. При блокере выполняй независимые части, укажи точную причину и команду для продолжения.
В своей директории создай README.md, REPORT.md, код, тесты, небольшие results/ с сырыми метриками и разрешёнными fixtures. Запиши версии, SHA, лицензии, команды, exit codes, окружение, что реально проверено, отклонения и воспроизведение. В конце: PASS/PARTIAL/FAIL/BLOCKED, ADOPT/ADAPT/REJECT/NEEDS MORE EVIDENCE, перечень изменённых файлов и конкретный следующий шаг. Не отмечай эксперимент завершённым без критериев из POC_PLAN.md.

Рабочая директория: experiments/03-contextual-nlp/. Цель: сравнить локальный контекстный анализ с baseline 02, выбрать кандидат для Alpha. Требуется воспроизводимая база/корпус/предсказания 02; если их нет, пометь зависимость и выполни только feasibility/prototype.

1. Проверь и зафиксируй актуальные совместимые версии Apache OpenNLP 2.x + испанские модели и UDPipe 1 + испанскую модель. Лицензии кода, моделей и train/data отдельно; ограничения распространения/NC явно. Не считать совместимость с JVM совместимостью с Android. Apertium — резервный кандидат при выявленном ограничении первых двух, не внедрять всё одновременно.
2. Реализуй минимальные адаптеры offline: sentence text → токены, исходные диапазоны, lemma, UPOS, FEATS (если доступны), dependencies (если есть), альтернативы/unknown. OpenNLP Android runtime; UDPipe NDK/JNI ARM64; не встраивать Python/backend. Проверить tokenizer alignment: NFC, составные слова, клитики, пунктуация, UTF-16 offsets; исходный текст не менять. Словарь из 02 для вариантов значения, NLP для леммы/POS, не имитировать WSD.
3. Одинаковый frozen corpus/holdout для baseline и каждого движка. Сравнить top-1 lemma/POS, candidate coverage, unknown/abstain и ложные уверенные разборы, FEATS где есть gold, MWE precision/recall/F1 на согласованных границах. Отдельно challenge: vino, fui, dímelo, voseo, darse cuenta de, banco; выводить неопределённость смысла. Не обучаться на holdout. Указать числитель/знаменатель и примеры ошибок; качество gold preliminary, если нет человеческой проверки.
4. Измерить на реальном ARM64 Samsung Galaxy S25 Plus offline: cold init, warm p50/p95 по 100+ предложениям/повторам, отдельно load/inference/DB, RAM, APK/модель/DB и интеграционные расходы. Не заменять device замерами Mac/эмулятора. При отсутствии устройства — команды и BLOCKED DEVICE.
5. Таблица сравнения SQLite-only / OpenNLP / UDPipe (+ Apertium если обосновано). Предложи один движок, либо конкретный следующий PoC. Ориентиры ≥90% top-1 lemma, ≥90% POS, p95 typical sentence ≤200 ms; отчёт о статистических ограничениях и trade-offs. Никаких ложных уверенных семантических выводов. Не отменяй контекстный NLP без согласования.

Критерии: честные сопоставимые предсказания и метрики, тест Android ARM64, лицензия и воспроизведение. Если только один кандидат технически запустился, не называй это полным сравнением.
