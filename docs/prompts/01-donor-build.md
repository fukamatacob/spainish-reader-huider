# PoC 01 — сборка и перенос Spanish Reader

Ты инженер, выполняющий один ограниченный технический эксперимент в репозитории fukamatacob/spainish-reader-huider. Прочитай SPEC.md, docs/POC_PLAN.md, docs/TECHNICAL_AUDIT.md и при необходимости docs/DESIGN_SYSTEM.md. Следуй актуальной SPEC, не историческим UX-решениям донора. Не реализуй весь продукт. Проверь git status, сохрани чужую работу, используй отдельную ветку/worktree либо уже выделенную рабочую ветку. Не пушь и не сливай main без явного указания. Не используй destructive reset. Не публикуй секреты, личные данные, большие базы/модели/APK и нелицензированные исходные данные. Для существенных загрузок/установок проверь объём и разрешение. Не запрашивай ключи в чат/логи; используй только разрешённый локальный секрет. Не выдавай результаты mock/эмулятора/предположения за live/device. При блокере выполняй независимые части, укажи точную причину и команду для продолжения.
В своей директории создай README.md, REPORT.md, код, тесты, небольшие results/ с сырыми метриками и разрешёнными fixtures. Запиши версии, SHA, лицензии, команды, exit codes, окружение, что реально проверено, отклонения и воспроизведение. В конце: PASS/PARTIAL/FAIL/BLOCKED, ADOPT/ADAPT/REJECT/NEEDS MORE EVIDENCE, перечень изменённых файлов и конкретный следующий шаг. Не отмечай эксперимент завершённым без критериев из POC_PLAN.md.

Рабочая директория: experiments/01-donor-build/. Цель: проверить исходный upstream https://github.com/awkay/spanish-reader на Mac Apple Silicon без изменения его исходного поведения.

1. Определи установленное окружение (macOS, arch, java, SDK, adb, Gradle wrapper, доступные устройства), не устанавливай молча пакеты. Выбери и зафиксируй фактический upstream commit SHA, не SHA дерева, прочитай LICENSE и notices; клонируй вне продуктового дерева/в ignored cache.
2. Изучи settings.gradle, build.gradle и реальные модули. Определи команды через ./gradlew projects/tasks; собери оригинальный debug APK и запусти существующие core/app unit tests. Instrumentation только при наличии устройства, не запускай неизвестные live API-тесты без разрешения. Если исходная сборка не работает, сохрани исходный лог; workaround только в отдельной копии и с diff. Не называй обход исходной сборкой.
3. Проверь наличие/границы/зависимости Tokenizer, sentence segmenter, PhraseLocator, TextDecoding, ImportCleaner, GlosserFactory, OpenAiCompatibleGlosser, AnthropicGlosser, OpenAiResponsesGlosser, TextCompleter, PreGlossPlanner, DeviceTts, BackupCodec (уточни фактические пути). Проверь соответствующие тесты. Не переносить Go/web/server sync, OCR, drills и старую модель учебных статусов как продукт.
4. Составь таблицу reuse/adapt/rewrite/exclude с файлами, SHA, лицензиями, зависимостями и evidence; выдели минимальный перенос без UI/backend. Проверь потенциальные лицензии транзитивных зависимостей отдельно от MIT донора. Не меняй SPEC. Подготовь черновик UPSTREAM.md в папке эксперимента (не утверждай, что код уже перенесён).
5. Если доступен adb, проверь установку debug APK только с согласия владельца, не удаляй существующее приложение/данные. Укажи APK path/размер и test reports; в отсутствие устройства дай команды и ручной сценарий.

Критерии: зафиксирован upstream commit, воспроизводимые команды и результат сборки/тестов, документированные ограничения, проверяемый список кандидатов на перенос; device отдельно. Никаких новых продуктовых функций.
