# PoC 04 — интерактивный Reader в Jetpack Compose

Ты инженер, выполняющий один ограниченный технический эксперимент в репозитории fukamatacob/spainish-reader-huider. Прочитай SPEC.md, docs/POC_PLAN.md, docs/TECHNICAL_AUDIT.md и при необходимости docs/DESIGN_SYSTEM.md. Следуй актуальной SPEC, не историческим UX-решениям донора. Не реализуй весь продукт. Проверь git status, сохрани чужую работу, используй отдельную ветку/worktree либо уже выделенную рабочую ветку. Не пушь и не сливай main без явного указания. Не используй destructive reset. Не публикуй секреты, личные данные, большие базы/модели/APK и нелицензированные исходные данные. Для существенных загрузок/установок проверь объём и разрешение. Не запрашивай ключи в чат/логи; используй только разрешённый локальный секрет. Не выдавай результаты mock/эмулятора/предположения за live/device. При блокере выполняй независимые части, укажи точную причину и команду для продолжения.
В своей директории создай README.md, REPORT.md, код, тесты, небольшие results/ с сырыми метриками и разрешёнными fixtures. Запиши версии, SHA, лицензии, команды, exit codes, окружение, что реально проверено, отклонения и воспроизведение. В конце: PASS/PARTIAL/FAIL/BLOCKED, ADOPT/ADAPT/REJECT/NEEDS MORE EVIDENCE, перечень изменённых файлов и конкретный следующий шаг. Не отмечай эксперимент завершённым без критериев из POC_PLAN.md.

Рабочая директория: experiments/04-reader/. Цель: маленький устанавливаемый Android harness, не полноценное приложение. Используй Terra Bento tokens и минимальную модель документа, stub Language Core с детерминированными переводами и управляемой задержкой. Никаких live API.

1. Сверь SPEC (Reader, жесты, история, popover), DESIGN_SYSTEM. Реализуй обычный многострочный текст, реальный TextLayoutResult/offset mapping и диапазоны токенов, не раскладывай каждое слово в отдельную кнопку, если это нарушает метрики текста. Поддержи punctuation, диакритику, italic/bold, слова возле края и переносы.
2. Single Tap сразу показывает локальный перевод; второй тап того же слова в пределах double-tap window раскрывает карточку без повторного lookup; поздний повтор закрывает. Long Press выделяет выражение, тап по другому слову меняет фокус, swipe/outside закрывает, scroll не засчитывается. Отменяй/игнорируй stale async ответ. В harness счётчик успешных lookup events для проверки; не подменять им реальные правила истории.
3. Popover только перевод и раскрытие, привязка над/под словом с учётом viewport, без затемнения и reflow. Фокус #BFD9F3, постоянный плоский янтарный marker #F3E7BC и более слабые из дизайн-системы. Сравни bounds/line breaks до/после фокуса и highlight; измерь реальные метрики, скриншоты не единственное доказательство. Проверить выражение через несколько строк и hit-testing.
4. Проверь размер текста, font scale, ориентацию/изменение layout, восстановление позиции по текстовому якорю, отсутствие потери/дублирования lookup при recomposition/перезапуске; TalkBack/доступность и touch conflicts. Напиши Compose UI tests, отдельно ручные сценарии на Samsung Galaxy S25 Plus. Полная карточка может быть минимальной заглушкой, геометрию и скролл тестировать, не утверждать окончательные пороги затухания.
5. Собери APK, укажи запуск, результаты UI tests, device/эмулятор отдельно, скриншоты/видео без личных данных, before/after bounds, проблемы и варианты исправления.

Критерии: ключевые жесты работают, ни один из проверенных режимов не меняет line breaks из-за подсветки, нет повторного запроса на Double Tap или ложных lookup при scroll, stale response безопасен, позиция восстанавливается. Без реального устройства статус проверки PARTIAL/BLOCKED DEVICE.
